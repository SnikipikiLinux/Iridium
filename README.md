# Iridium

Iridium is a program that lets you download convert and compress video files

## Features

- Download videos
- Convert videos to other formats
- Compress videos to make them smaller

## Download

## Requirements

- Windows 10 or 11
- Other systems have not been tested

## Is it safe

Yes and you do not have to take my word for it
- All the source code is in this repo so you can read it yourself
- You can upload the exe to VirusTotal or Tria.ge and check it
- Some antivirus programs flag new unsigned programs and this is called a false positive
- Windows SmartScreen may show a warning because a code signing license costs around 200 dollars and i cant afford it yet

Iridium is built with Python and uses FFmpeg for converting and compressing videos and FFmpeg is included in the download
